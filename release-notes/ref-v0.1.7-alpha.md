# Titan Approx DPS 0.1.7-alpha

Tooltip damage values use sky blue, ability subtotals pink, DPS amber, percentages green and lifetime totals gold. All value-pair separators use violet slashes. Unavailable values use gray.

The report heading is shortened to Report damage / DPS, and the percentage footer explains the group denominator. Existing data and percentages use their existing calculations.

The website illustration in website-assets/titan-approx-dps-tooltip-guide.png explains the screenshot's character lifetime, weapon lifetime, report damage, combat DPS, auto/ability split, spell shares and pet contribution. It uses the built-in image generation tool. The prompt is retained alongside the asset. Website files are excluded from the runtime ZIP.

Validation includes the project suite and tooltip rendering with WoW color markup. Live-client visual acceptance remains pending. Install the runtime folder and run /reload when upgrading from 0.1.5 or later. Older versions require a full restart to load SpellRules.lua.
