# Titan Approx DPS 0.1.8-alpha

Aligned the tooltip emphasis with the illustrated guide. Report damage and DPS, plus auto-attack and ability headings, now use a gold label. Damage amounts remain blue, ability totals pink, DPS amber, percentages green, lifetime totals gold and unavailable values gray. Violet slash separators use a brighter shade for better visibility in the in-game tooltip.

This release changes presentation only. It does not change collected statistics or calculations.
